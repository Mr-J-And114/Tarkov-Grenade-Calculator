# Tarkov Grenade Calculator / 塔科夫榴弹射击辅助

A small ballistic calculator for grenade launcher usage in Escape from Tarkov.  
一个用于《逃离塔科夫》的榴弹弹道辅助计算器。

## Author / 作者

Mr.J.And

## Repository / 仓库

Mr-J-And114/Tarkov-Grenade-Calculator

## Map Coordinate Source / 地图坐标来源

Coordinates are currently obtained from Tarkov.dev maps:  
坐标数据目前来自 Tarkov.dev 地图：

https://tarkov.dev/maps/

## Features / 功能

1. Calculate elevation by distance and height difference.  
   根据距离和高低差计算俯仰角。

2. Calculate azimuth and elevation by coordinates.  
   根据坐标计算方位角和俯仰角。

3. Generate a 0-1000m horizontal firing table.  
   生成 0~1000 米水平面射表。

4. Temporarily override projectile velocity.  
   临时覆盖炮弹初速。

5. Restore default AGS data.  
   恢复默认 AGS 数据。
